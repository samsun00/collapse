# Collapse Widget

[![Deploy](https://github.com/samsun00/collapse/actions/workflows/deploy.yml/badge.svg)](https://github.com/samsun00/collapse/actions/workflows/deploy.yml)
[![GitHub Pages](https://img.shields.io/badge/demo-online-green)](https://samsun00.github.io/collapse/)

Виджет сворачивающихся/разворачивающихся блоков на чистом JavaScript.

## Особенности

- 🚀 Работает без jQuery
- 🎨 Красивая анимация
- 📱 Адаптивный дизайн
- 🔧 Независимые блоки
- ⚡ Быстрый и легкий

## Демонстрация

Посмотреть живую демонстрацию можно по ссылке: [GitHub Pages](https://samsun00.github.io/collapse)

## Установка и запуск

```bash
# Клонируйте репозиторий
git clone https://github.com/samsun00/collapse.git

# Перейдите в папку проекта
cd collapse

# Установите зависимости
npm install

# Запустите в режиме разработки
npm start

# Соберите проект
npm build

# Деплой на GitHub Pages (вручную)
npm run deploy

```
