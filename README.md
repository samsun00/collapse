# Collapse Widget

[![Build status](https://ci.appveyor.com/api/projects/status/8wxec3aa71ulddg2?svg=true)](https://ci.appveyor.com/project/samsun00/collapse)

[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Live-brightgreen)](https://samsun00.github.io/collapse)

Виджет сворачивающихся/разворачивающихся блоков на чистом JavaScript.

## Особенности

- 🚀 Работает без jQuery
- 🎨 Красивая анимация
- 📱 Адаптивный дизайн
- 🔧 Независимые блоки
- ⚡ Быстрый и легкий

## Демонстрация

Посмотреть живую демонстрацию можно по ссылке: [GitHub Pages](https://samsun00.github.io/collapse)

## Установка и запуск

```bash
# Клонируйте репозиторий
git clone https://github.com/samsun00/collapse.git

# Перейдите в папку проекта
cd collapse

# Установите зависимости
npm install

# Запустите в режиме разработки
npm start

# Соберите проект
npm build

# Деплой на GitHub Pages (вручную)
npm run deploy

```
